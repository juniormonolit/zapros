# UX: канбан и фильтры

**Дата:** 2026-06-01

## Принципы

- Поведение близко к **Bitrix24**: канбан + таблица + фильтры, завершённые скрыты.
- Снабженец — две зоны: **Задачи** и **Запросы** (табы в шапке `/app`).
- Поставщик — одна доска **Мои запросы**.

## Навигация снабженца

```text
[Задачи] [Запросы] [Таблица]     🔍 Поиск     + Новая задача
```

## Карточка задачи

```text
┌─────────────────────────────────────────────┐
│ № 113153  ·  мск_Утеплитель     [Bitrix ↗]  │
│ Утеплитель Минеральная вата…                │
│ Запросы: 2 завершено · 1 в работе · 3 всего │
├─────────────────────────────────────────────┤
│ ☑ │ Товар                          │ Кол-во │
│ ☑ │ Лента клейкая…                 │ 20 шт  │
│ ☐ │ Утеплитель Роквул…             │ 195 шт │
├─────────────────────────────────────────────┤
│ [Создать запрос]  Список запросов ↓         │
└─────────────────────────────────────────────┘
```

## Карточка запроса (снабженец)

```text
Заголовок · статус · дедлайны по поставщикам
Вкладки: [Позиции] [Ответы] [Поставщики] [Лента]
Кнопки: Уточнение · Выбрать победителя · Закрыть браком
```

**Ответы:** матрица строк × поставщики, badge «v2 актуально».

## Дерево поставщиков (модал отправки)

```text
▼ мск_Опт                    [☑]
    ☐ СтройТепло
    ☑ Иванов
▼ мск_Производители          [☐]
    ☐ Роквул-партнёр
─────────────────────────────
Подсказка: для «мск_Утеплитель» → группа мск_Опт
[Отмена]  [Отправить запрос]
```

## Канбан запросов (снабженец)

Горизонтальные колонки, горизонтальный скролл на mobile.

Дефолтные колонки: Новый | Ожидаем | Есть ответ | Уточнение | В работе

Переключатель: `☐ Показать завершённые` → добавляет Не прошли | Победа | Без ответа

## Фильтры (drawer справа)

```text
Группа стадий:  [Запрос в работе ▼]
Дата создания:  [____] — [____]
Поставщик:      [мультивыбор]
Категория:      [____]
Номер Bitrix:   [____]
────────────────
[Сбросить]  [Применить]
```

## Поставщик: форма ответа

По каждой строке:

```text
Лента клейкая 50мм × 50м · 20 шт
  Цена с НДС:     [______] руб
  Цена нал:       [______] руб   (если разрешено)
  Цена без НДС:   [______] руб
  ☐ Цена с доставкой   Доставка: [______] руб
  ○ В наличии   ○ Срок: [__] дн.
  Комментарий: [________________]
```

Внизу: комментарий к ответу, [Отправить ответ] [Новая версия]

## Быстрые сигналы (снабженец)

Кнопки над тредом:

`Есть дешевле` · `У заказчика дешевле` · `В работе`

→ modal с опциональным комментарием → event в ленте.

## Цвета статусов (рекомендация)

| Статус | Цвет |
|--------|------|
| Новый / ожидаем | neutral |
| Есть ответ | blue |
| Уточнение | amber |
| В работе | green |
| Проигран / без ответа | gray (скрытые) |
| Победа | emerald |

См. `design/design-system-light-dark-theme.md` в корне репозитория.

## Доступность

- Drag-and-drop: альтернатива — меню «Переместить в…»
- Контраст бейджей в dark mode
