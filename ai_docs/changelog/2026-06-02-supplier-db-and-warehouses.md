# Changelog — 2026-06-02: Поставщики как гибкая БД + склады (дизайн)

## Дизайн-решения (приняты с пользователем)

- **Поставщик — гибкая БД с кастомными полями**, которые админ добавляет по мере необходимости.
  Хранение значений — **EAV** (`supplier_field_values`, строка на поле) + схема
  `supplier_field_definitions` (ведёт админ).
- **Типы полей**: `text`, `masked_text` (ФИО/телефон с маской ввода), `number`, `date`, `boolean`,
  `single_select`, `multi_select` (галочки из заданного админом списка, напр. «Форма оплаты:
  С НДС / Без НДС / Нал» — старший снабженец отмечает, как поставщик может работать).
- **Ядро + кастом сверху**: `name`, контакты, `sourcing_status`, `works_in_zapros` остаются
  колонками; кастомные поля — поверх через EAV.
- **Склады поставщика** (`supplier_warehouses`): `name`, `address`, `working_hours` (свободный текст),
  + `warehouse_nomenclature_rules` (правила привязки номенклатур: `contains/starts_with/.../regex` +
  значение, напр. `contains "ЛСР"`). Правила сейчас только хранятся; применяются при будущем
  мэтчинге номенклатур → склад → поставщик → история цен.
- **Приоритет**: сначала **Фаза 3** (запросы — ядро сквозного потока), затем расширение
  поставщиков (Фаза 7.7).
