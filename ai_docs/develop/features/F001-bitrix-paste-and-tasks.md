# F001: Bitrix paste и задачи

**Дата:** 2026-06-01  
**Статус:** MVP

## Цель

Снабженец вставляет текст задачи из Bitrix24 → система создаёт **Задачу** с разобранными полями и таблицей товаров. Ручная правка до сохранения.

## User stories

1. Как снабженец, я вставляю текст из Bitrix и вижу превью распознанных полей.
2. Как снабженец, я исправляю поля, если парсер ошибся.
3. Как снабженец, я сохраняю задачу с уникальным номером Bitrix.
4. Как снабженец, при дубликате номера я вижу предупреждение и могу открыть существующую задачу.

## Таблица товаров

Bitrix экспортирует таблицу товаров в **двух форматах** — парсер обязан поддерживать оба:

### Формат A — табличный (пример 113153)

- Блок после `Продукция из товаров:`
- Строки до `Общая сумма` / `добавить чек-лист`
- Разделитель: таб; есть строка-заголовок с колонкой «Товар»
- Колонки парсера: **Товар**, **Кол-во**, **Комментарий** (остальные колонки Bitrix не импортируются)

### Формат B — построчный «тире-формат» (пример 113881)

- Строки вида `<Товар> - <Кол-во> <Ед> - <цена> руб/ед - <сумма> руб`
  (разделитель полей — ` - `, без табов и без строки-заголовка)
- Конец таблицы — маркер `Итого:` (а также `Цена которую предлагают конкуренты:` и т.п.)
- Импортируем: **Товар** (`name`), **Кол-во**+**Ед** (`quantity`/`unit`); цена/сумма НЕ импортируются
- Пример строки: `маты прошивные МП 50, 100 мм - 1.0000 упак - 0.00 руб/упак - 0 руб`
  → `name="маты прошивные МП 50, 100 мм"`, `quantity=1`, `unit="упак"`

Парсер выбирает формат автоматически (наличие табличного заголовка → A, иначе → B).
Запрещённые ценовые колонки/части не попадают в результат ни в одном формате.

**Не импортировать / не показывать поставщику:**

- Наша цена, Сумма, Цена из калькулятора, Цена конкурента

## URL Bitrix

1. По `category` ищем запись в `bitrix_group_settings.name`.
2. Подставляем `bitrix_task_number` в `url_template` (`{task_id}`).
3. Если группа не найдена — выбор шаблона вручную в превью.

Пример (текущая настройка):

```text
мск_Утеплитель → https://td.monolit-crm.ru/workgroups/group/17/tasks/task/view/{task_id}/
```

## UI

1. Экран «Новая задача»: textarea paste + кнопка «Разобрать».
2. Форма превью: все поля редактируемые, таблица товаров (добавить/удалить строку).
3. «Сохранить задачу» → редирект на карточку задачи.

## Валидация

- `bitrix_task_number` обязателен, integer > 0
- Минимум 1 `task_item`
- `delivery_date` — валидная дата
- UNIQUE `bitrix_task_number` per system (не per user)

## API / Server Action

- `parseBitrixPaste(raw: string): ParsedTaskPreview`
- `createTask(parsed, userId): taskId`
