# F008: Админ и настройки

**Дата:** 2026-06-01  
**Статус:** MVP

## Цель

Один администратор управляет пользователями, поставщиками, группами поставщиков и шаблонами ссылок Bitrix.

## User stories

1. Как админ, я создаю пользователя с ролью и привязкой к поставщику.
2. Как админ, я отправляю invite / временный пароль.
3. Как админ, я веду справочник поставщиков и групп (CRUD).
4. Как админ, я настраиваю «название группы Bitrix → URL шаблон».
5. Как админ, я опционально связываю категорию задачи с группой поставщиков (подсказка).

## Разделы настроек

### Пользователи

| Поле | Описание |
|------|----------|
| email | Уникальный |
| full_name | |
| role | admin / procurement / supplier |
| supplier_id | Обязателен для supplier |
| is_active | Деактивация без удаления |

Операции через Server Action + Supabase Admin API (`service_role`).

**Ограничение MVP:** один пользователь с `role=admin` (проверка при создании второго).

### Поставщики

- name, is_active
- Привязка N пользователей (profiles.supplier_id)

### Группы поставщиков

- name, sort_order
- members: many-to-many

### Bitrix groups

| name | url_template |
|------|--------------|
| мск_Утеплитель | `https://td.monolit-crm.ru/workgroups/group/17/tasks/task/view/{task_id}/` |

`{task_id}` — плейсхолдер номера задачи.

### Подсказки категорий

`category_supplier_group_hints`: category text → supplier_group_id

### Глобальные параметры (`app_settings`)

| Параметр | Дефолт | Описание |
|----------|--------|----------|
| `response_deadline_days` | 10 | Срок ответа (кал. дни) до архива |
| `cash_to_noncash_ratio` | 0.84 | Коэффициент нал→безнал для сравнения |

### Уведомления (см. F009)

Настройки уведомлений у каждого пользователя в его ЛК (email opt-in), не в админке. Админ управляет только пользователями и справочниками.

## Доступ

- Route `/admin` только role=admin.
- Снабженец и поставщик не видят настройки.

## Критерии приёмки

- [ ] Созданный поставщик логинится и видит только свои invites
- [ ] Снабженец создаётся без supplier_id
- [ ] Новая Bitrix-группа подхватывается парсером без деплоя кода
- [ ] Деактивированный пользователь не входит
